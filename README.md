# 📝 SQUAD-12-Quiz

Quiz do **Módulo 1 da PDA** desenvolvido pelo time **SQUAD 12**, com o objetivo de reforçar os conteúdos aprendidos de forma interativa.  
Neste projeto, atuei como **líder da equipe**, coordenando o desenvolvimento e a organização das atividades.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

---

## 🎨 Funcionalidades do Quiz

- Perguntas de múltipla escolha com pontuação automática  
- Feedback imediato para respostas corretas e incorretas  
- Interface simples, responsiva e interativa  
- Estrutura de fácil manutenção e expansão para novos módulos  

---

## 📂 Estrutura do Projeto

```bash
📦 SQUAD-12-Quiz

```
